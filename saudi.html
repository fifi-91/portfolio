03How we got there

Three moves, one platform.

Behavioural research reshaped the IA from search → buy to discover → finance → manage → community. The design system enforced parity across LTR and RTL from atoms up.

Homeownership is a relationship, not a transaction.

Behavioural research surfaced the real friction: not interest, but trust. Maintenance was the most-needed, least-trusted service category. Buyers wanted clearer pricing and transparent communication before, during and after.

  • Qual + quant studies with prospective buyers and existing residents
  • Service-quality benchmarking across the regional category
  • Insight reshaped IA from search → buy to discover → finance → manage → community

One platform strategy. Three product surfaces.

Rather than ship three apps, we treated property acquisition as a continuous journey and structured a single super-app — designed to flex per surface, while sharing a system underneath.

  • End-to-end IA across onboarding, search, financing, scheduling, aftercare
  • Bilingual-first thinking — RTL parity, dynamic text scaling, cultural icon review
  • Design-to-dev parity via live Storybook, zero drift between Figma and code

Atoms to organisms — both languages, from day one.

A 3,000+ component system built atomically: tokens, components, organisms, templates, pages. Every level shipped with LTR and RTL specs, accessibility specs, code props and visual regression tests.

  • WCAG 2.1 AA, light/dark, dynamic type, scaling
  • Component docs with code, props, do/don't, RTL behaviours
  • 35% reduction in design-to-dev turnaround across the org
04Atomic system

3,000+ components, composed across one atomic system.

Tokens at the base — colour, type, spacing, motion. Composed up into atoms, molecules, organisms, and finally templates and pages. Step through the layers — every level here is built from the one before it.

Decisions, not pixels.

Every visual decision — colour, type ramp, spacing, radii, elevation, motion — lives once, as a token. Themes are dictionaries; everything above this layer reads from them.
